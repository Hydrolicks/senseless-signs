# Senseless signs

The 49 American Sign Language (ASL) words that the Senseless device recognizes, each shown by an animated stick figure. The page is linked from the QR code on the Senseless project poster.

Live page: https://hydrolicks.github.io/senseless-signs/

Senseless is a final project at Ruppin Academic Center (Department of Electrical and Electronics Engineering) by Asaf Amrani and Gil Ohana, supervised by Dr. Benjamin Gur Solomon. It turns ASL signs and English speech into text on a Raspberry Pi, fully offline.

Each figure replays one of our own recorded takes (hand and upper-body landmarks only, no video). `index.html` is self-contained: no build step, no external requests except the web font.
